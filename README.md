# md2smd

a simple cli tool to convert markdown files to [supermarkdown](https://zine-ssg.io/docs/supermd)
and [supermarkdown](https://zine-ssg.io/docs/supermd) to markdown

specially made this to aid myself while writing content using [frontmatter](https://frontmatter.codes).
as there is no direct smd compatible editor yet. and frontmatter is the easiest
standard to manage content.

btw .. i have tried replicating the specs as accurately as possible,
